# ElectroReck | Techspardha '25-26 Event Page

A responsive event showcase website for **ElectroReck**, the electrical engineering club of **NIT Kurukshetra**. Built as a web development assignment using only HTML, CSS and vanilla JavaScript (no frameworks).

**Live website:** https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/
**GitHub repository:** https://github.com/YOUR-USERNAME/YOUR-REPO-NAME

## Features

- Responsive layout for mobile, tablet and desktop (Flexbox and CSS Grid)
- Sticky navigation bar with smooth scrolling, social icons and institute logo
- Hero section with an interactive oscilloscope-style wave animation
- 4 event cards (Electrica, UPSC Challenge, Digi Spark, Advanza), each with an image, category badge, date/time, venue and a Register button
- Category filter (All / Technical / Creative / Academic) using vanilla JavaScript
- Breaker-switch toggle on each card to reveal details
- Registration modal with form validation and a confirmation message
- Printable registration pass with a unique pass ID
- "Add to calendar" button that downloads an `.ics` file for each event
- Event poster gallery with a full-size viewer
- Quick tools: Ohm's law calculator and a logic gate playground
- Registrations are stored in the browser using `localStorage`

## Tech stack

HTML5, CSS3 (Flexbox, Grid, custom properties), JavaScript (ES6), Google Fonts

## Run locally

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server** (or double-click `index.html`).

## Deployment

Deployed with GitHub Pages: Settings > Pages > Deploy from a branch > `main` / `(root)`.
